PROJECT 01 · SEP — DES 2025

SIPOSSistem Informasi Posyandu

Sistem informasi berbasis website untuk membantu digitalisasi pengelolaan data Posyandu, khususnya data balita dan ibu hamil. Informasi peserta, pemeriksaan, jadwal kegiatan, serta ringkasan statistik disajikan dalam satu sistem.

Fitur utama

  • Dashboard statistik peserta dan visualisasi data kesehatan.
  • Pengelolaan data balita dan ibu hamil.
  • Pencatatan pemeriksaan serta jadwal kegiatan Posyandu.
  • Pembuatan dan ekspor laporan PDF.
PHPMySQLHTMLCSSJavaScript

Fokus: digitalisasi pencatatan dan penyajian informasi kesehatan Posyandu.

PROJECT 02 · JAN 2026 — SEKARANG

SINEMUSistem Informasi Barang Hilang dan Temuan

Solusi digital untuk membantu masyarakat Kabupaten Indramayu melaporkan, mencari, dan mengklaim barang hilang maupun barang temuan. SINEMU dikembangkan dalam dua platform yang saling melengkapi: website untuk akses informasi dan pengelolaan, serta aplikasi mobile untuk kemudahan akses pengguna.

Fitur utama

  • Pelaporan barang hilang dan barang temuan.
  • Pencarian barang dengan filter kategori, waktu, dan wilayah.
  • Pengajuan klaim serta pemantauan status laporan.
  • Dashboard pengelola untuk meninjau laporan dan verifikasi klaim.
  • Informasi lokasi pengambilan dan petunjuk arah.
PHPLaravelBootstrapJavaScriptMySQLDartFlutterGit & GitHub
Pengembangan berlanjut

Fitur AI sedang dikembangkan sebagai lanjutan project, mencakup chatbot AI berbasis web dan dukungan analisis klaim seperti pencocokan data, skor kemiripan, serta rekomendasi untuk membantu proses verifikasi. Hasil keputusan klaim tetap ditinjau oleh administrator.
